SAFE360 PROTOTYPE – OFFLINE 360° DEMONSTRATION

1. Extract the entire ZIP before opening the prototype.
2. Open Prototype/index.html in Chrome or Microsoft Edge.
3. The warehouse panorama is stored locally in Prototype/assets/warehouse_panorama.png.
4. Drag left/right across the warehouse to rotate through the 360° panorama.
5. Scroll to zoom.
6. Rotate to locate the five labelled hazard hotspots: PPE, Manual Handling, Spill, Forklift and Exit.
7. Select a hotspot, answer the investigation question, choose the related hazard and classify the risk.
8. Complete the 3-question Knowledge Check.
9. Use Dashboard to view the saved prototype attempt.

OFFLINE ROBUSTNESS
The main demonstration uses a local panorama surface, so the warehouse remains visible even when the internet/CDN is unavailable. Pannellum can be used as an optional online enhancement, but the core prototype does not depend on it.
